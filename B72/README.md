# h(B_{7,2}) = 1 の GRH なしの証明に向けた証明書キット（第 2 版）

B_{7,2} は Q の円分 Z_7 拡大の第 2 層（次数 49、導手 343、判別式 7^138）。

## 証明の構成
1. 各分解素数 p（p^6 ≡ 1 mod 343）について、ノルム ±p の整数環の元 α を与える（証明書の 1 行）。
   K/Q は Galois なので、p の上の 49 個の素イデアルは全て単項。
2. Miller の補題（J. Number Theory 150 (2015), Lemma 2.2）に単項と確認した素数の集合 S を入れ、h < 2c√π/(49B) を得る。
3. Masley の Rank Corollary（Compositio Math. 37 (1978), Cor. 2.15）を B_{7,2}/Q（次数 49 の巡回拡大）に使う。
   h(B_{7,1}) = 1 なので、素数 ℓ ≠ 7 が h を割れば ℓ^f | h（f は ℓ の mod 49 での位数）。7 ∤ h は岩澤の定理。
   ℓ^f の最小値は 197（ℓ = 197, f = 1）。したがって h < 197 ならば h = 1。

## 二つの目標
- **自己完結版**：約 2.2×10^7 まで（分解素数 28,381 個）で h < 161。上の 1〜3 だけで h = 1。
- **短縮版**：約 1.2×10^7 まで（16,093 個）で h < 3291。2 と 7 以外の素数 < 10^4 が h を割らないこと
  （Hakkarainen の表に導手 343 の行が無いこと、または円単数による直接の判定）を併用して h = 1。

## 実行（Mac / Linux）
    pip install cypari2 python-flint        # Sage を使う場合:  sage -pip install python-flint
    ./run_all.sh 12000000 6                 # 上限と並列数。Sage の場合は先頭に PYTHON="sage -python"
    ./status.sh                             # 進み具合
    python3 verify_cert.py cert*.txt        # 最終確認（PARI を使わない独立な検証）
途中で止めても、同じコマンドで続きから再開できる。上限を 22000000 に変えて再実行すれば自己完結版まで延ばせる。

## ファイル
- `gen_cert.py`：証明書の生成（PARI）。内部の bnfinit は GRH を仮定するが、出力は検証器で無条件に確認される。
- `verify_cert.py`：独立な検証器（python-flint のみ）。体の定義多項式を作り直し、各行の整数性とノルムを
  厳密に確認し、B を区間演算で下から評価する。
- `run_all.sh`, `status.sh`：並列実行と進み具合の表示。
- `cert_B72_pilot.txt`, `cert_cloud_*.txt`：生成済みの証明書 285 個（3.2×10^5 未満の一部まで、検証済み）。

## 見積り
- 生成は 1 個あたり平均 10 秒前後（クラウドの 2 コア環境での実測。まれに 1 個で数分かかる）。
  短縮版で約 45 コア時間、自己完結版で約 80 コア時間。証明書は 1 行約 8 KB（全体で 130〜230 MB）。

## 未確認の点
- Hakkarainen の表の 343 の行が無いことの原本での目視確認（短縮版を使う場合）。
- この結果が既出でないこと（MathSciNet の被引用 34 件と題名検索では該当なし）。
