## 1. 数学の確認

### 1.1 (1) 完全分解の判定：正しい
$\mathrm{Gal}(K/\mathbb{Q})\cong(\mathbb{Z}/243)^\times/H$、$H=\{\pm1\}$ である。$q\ne3$ が完全分解することと、Frobenius $q \bmod 243$ が $H$ に入ることは同値。$(\mathbb{Z}/243)^\times$ は巡回群なので、$H$ はその 2 等分点全体で、$q\in H\iff q^2\equiv1\iff q\equiv\pm1 \pmod{243}$。コードの `split`（$q^{p-1}\equiv1 \bmod M$）もこれと同じ。

### 1.2 (2) 3 の上の素イデアル：正しい
$N_{\mathbb{Q}(\zeta)/K}(1-\zeta)=(1-\zeta)(1-\zeta^{-1})=2-\eta_0$ で、$|N_{K/\mathbb{Q}}(2-\eta_0)|=\Phi_{243}(1)=3$。3 は $K$ で完全分岐するから、$(2-\eta_0)$ が 3 の上の唯一の素イデアルである。自作コードでも $\mathrm{Res}(\Phi_{243},2-x-x^{242})=9=3^2$ を確かめた。

### 1.3 (3) 真部分体の類数と完全分解しない素数：論理は正しいが、出典に穴がある
- **論理。** $r\ne3$ が完全分解しないとき、分解体 $D$ は真部分体であり、$K/D$ で $r$ の上の素イデアルは不分岐かつ惰性である。したがって $\mathfrak{P}=\mathfrak{p}_DO_K$ で、$h(D)=1$ なら $\mathfrak{P}$ は単項。$r=3$ は (2) で処理されている。
- **補足（簡略化できる）。** $k_{3^3}/k_{3^2}/k_3/\mathbb{Q}$ では 3 が完全分岐するので、類群のノルム写像は全射になる。よって $h(k_{3^2})\mid h(k_{3^3})$、$h(k_3)\mid h(k_{3^2})$ で、必要なのは $h(k_{3^3})=1$ だけである。階数定理の側でも、効くのは最大の真部分体 $k_{3^3}$ のノルム $1+\sigma^{27}+\sigma^{54}=\Phi_{81}(\sigma)$ だけである。
- **出典の穴。** Miller（arXiv:1410.2921, Table 1）は $k_{3^3}$ の典拠を Masley (1978) としている。しかし [numdam の Masley 原典](https://www.numdam.org/item/CM_1978__37_3_297_0) の Theorem 3.2 は「素数冪導手 70 未満の実アーベル体は類数 1」である。同じ節には、70 を 100 に延ばすには零点についての仮定が要る、と書かれている。導手 81 の記述は、読める範囲には見つからなかった（Table 2 は OCR が読めない）。したがって、「Masley 1978」だけを根拠に引くのは不十分である。
- **代わりの出典。** [Miller, LMS J. Comput. Math. 17 (2014)](https://cambridge.org/core/services/aop-cambridge-core/content/view/EE3E7A999C3A29B5D541F55B1CD67768/S1461157014000382a.pdf/class-numbers-of-real-cyclotomic-fields-of-composite-conductor.pdf) の Theorem 1.1 は「合成数 $m$ で $\varphi(m)\le116$ なら $h^+_m=1$（例外 136、145、212）」で、81 も合成数に当たる。同じ論文は、素数冪の 125 と 256 もこの定理の中で扱っている。序文には、Masley と van der Linden が「$m\le200$、$\varphi(m)\le72$ の合成数導手」を無条件に決めた、ともある。ただし、81 が明示されているわけではない。
- **自己完結した証明（推奨）。** Miller の補題を $S=\emptyset$ で $k_{3^3}$（判別式 $3^{94}$）に使う。積分は自作の厳密な Simpson 法（§3.4）で $c=8$ とすると、$h(k_{3^3})<5.9601$ になる。階数定理の閾値は $\min_\ell \ell^{\mathrm{ord}_{27}\ell}=109$、$3\nmid h$ は岩澤の定理による。よって $h(k_{3^3})=1$ である。ここで使う $h(k_{3^2})=1$ と $h(k_3)=1$ も同様に、$S=\emptyset$ で $h<1.332$（閾値 19）と $h<1.682$（閾値 4）が出る。PARI の `bnfcertify` でも 1 を確認した。論文ではこの段落を入れることを勧める（`/home/claude/rel_audit/code/subfields.py`）。

### 1.4 (4) 行から単項性へ：正しい
- $\alpha=c+\sum a_i\eta_i$ は代数的整数の整数係数の一次結合なので、$O_K$ に入る。行では $q$ がノルムの分解に現れるから $N(\alpha)\ne0$ である。
- $(\alpha)=\prod\mathfrak{P}^{v_\mathfrak{P}}$ で、$|N(\alpha)|=\prod N\mathfrak{P}^{v_\mathfrak{P}}$。$q$ は完全分解するので、$q$ の上の素イデアルのノルムはどれも $q$ で、$v_q(N\alpha)=\sum_{\mathfrak{P}\mid q}v_\mathfrak{P}(\alpha)=1$ となる。よって、ちょうど 1 個の $\mathfrak{Q}$ が指数 1 で現れる。他の素イデアルは、$r=3$、完全分解しない $r$（剰余次数 $>1$ でも可）、既知の完全分解素数 $r$ の上にある。どれも単項なので、$\mathfrak{Q}$ も単項。Galois 共役で、$q$ の上の素イデアルはすべて単項になる。高い冪で割れる素数 $r\ne q$ は、$r$ の上の素イデアルがすべて単項なら問題ない。$q$ 自身の冪が 2 以上の行は、`dict(fac).get(q)==1` で拒否される。
- **一般の形式（基礎証明書）。** 上から順に処理するので、循環はありえない。$10^7$ を超える補助素数 539 個（最大 8,727,408,181）も、同じファイルの先に出てくる行で証明されている。範囲の結果は使っていない。

### 1.5 (5) Miller の補題：仮定と定数は合っている
- ar5iv の HTML 版（[arXiv:1410.2921](https://ar5iv.labs.arxiv.org/html/1410.2921)、WebFetch による要約経由）で Lemma 2.2 を確認した。$K$ は総実体、$F(x)=e^{-(x/c)^2}/\cosh(x/2)$、$S$ は「$K$ で完全分解して単項素イデアルになる素数」の部分集合、$B=\frac{\pi}{2}+\gamma+\log8\pi-\log\mathrm{rd}(K)-\int_0^\infty\frac{1-F}{2}\bigl(\frac1{\sinh(x/2)}+\frac1{\cosh(x/2)}\bigr)dx+2\sum_{p\in S}\sum_{m\ge1}\frac{\log p}{p^{m/2}}F(m\log p)$ で、$B>0$ なら $h<2c\sqrt\pi/(nB)$。コード（`bound`）はこれと一致する。
- $m\le8$ での打ち切りと $S$ を部分集合に取ることは、項が非負なので下界として正しい。

### 1.6 (6) 階数定理と岩澤の定理：正しい
- Masley の Cor. 2.15 を原典（numdam）で確認した。$E/F$ は次数 $n$ の巡回拡大、$p\nmid n$、$p$ は中間体のどの類数も割らない、という仮定のもとで、$p\mid h(E)$ なら $p^f\mid h(E)$（$f$ は $p \bmod n$ の位数）である。Miller が引いている「素数次」の形は使えず、この一般形を引く必要がある。
- 閾値は sympy で再計算して 163 になった（$163\equiv1 \bmod 81$。$\ell^{\mathrm{ord}_{81}\ell}<400$ となる $\ell\ne3$ は 163 だけ）。
- 岩澤の定理：$K/\mathbb{Q}$ は 3 冪次の巡回拡大で、分岐は 3 だけ、しかも完全分岐。$3\nmid h(\mathbb{Q})$ から $3\nmid h(K)$ が従う。
- $h<99.88$ なら、$h$ は $3$ 以外の素因数をもたない（あれば $h\ge163$ になる）。$3\nmid h$ と合わせて $h=1$。

### 1.7 $k_{7^2}$ の格子ブロック：正しい

## 6. 修正の一覧

1. 論文と README で、$h(k_{3^3})=1$ の典拠を「Masley 1978」だけにしない。Miller (LMS 2014) Thm 1.1 と van der Linden (1982) を挙げ、§1.3 の自己完結した証明（$S=\emptyset$ で $h(k_{3^3})<5.9601<109$）を本文に入れる。`docs/literature.md` の表の該当行も直す。
2. `aggregate.py` で和と個数を自分で計算し直す。$A<B$、`rows==split_primes`、終点、体 $(3,4)$ を検査する。
3. 要約の数値を整数演算による 10 進文字列にする。浮動小数を通さない。
4. ワークフロー：`pipefail` を付ける。失敗時に要約をアップロード・commit しない。python-flint の版を固定する。要約に `verify.py` の sha256 と run ID を記録する。
5. 論文では、範囲の形式の帰納法を明示的に書く（「$A$ 未満で成り立てば $[A,B)$ で $q$ についての帰納法」と「区間が 0 から隙間なく続くこと」）。基礎証明書の補助素数が自己完結していることも書く。
