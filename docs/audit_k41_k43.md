## 1. 体ごとの前提（`fieldp.py`、`model_check.py`）

記号：$M=p^2$、$K=k_p$、$\tau(\eta_i)=\eta_{i+1}$、$s=\tau^{-1}$。

### 1.1 周期の定義：整合している

| | $k_{41}$ | $k_{43}$ |
|---|---|---|
| $M$ | 1681 | 1849 |
| $M$ を法とする最小の原始根 $g$ | 6 | 3 |
| $H=\{x:x^{p-1}=1\}$ の位数 | 40 | 42 |

- $g$ の位数が $p(p-1)$ であることは、冪を全部並べて確かめた。$H=\langle g^p\rangle$（`verify.py` の定義）は $\{x:x^{p-1}=1\}$ と一致し、$H\to(\mathbb{Z}/p)^\times$ は全単射。$E_i=g^iH$（$i=0,\dots,p-1$）は $(\mathbb{Z}/M)^\times$ の分割。$g^p\in H$ なので $\eta_{i+p}=\eta_i$。$\zeta\mapsto\zeta^g$ は $E_i$ を $E_{i+1}$ に移すので、$\eta_i\mapsto\eta_{i+1}$ を引き起こす。番号付けは `verify.py` の `exps` と同じである（コードを読んで照合）。
- 乗法の表 $\eta_i\eta_j=c_{ij}+\sum_km_{ijk}\eta_k$ を 2 通りで作り、一致した：式 $\eta_i\eta_j=\sum_{h\in H}S(g^i+g^jh)$（$S(0)=p-1$、$p\mid x\ne0$ なら $S(x)=-1$、それ以外は $S(x)=\eta_{\mathrm{ind}(x)}$）と、指数 $a+b$ の数え上げ（`audit/k37/field37.py` の方法）。表は $i\mapsto i+1$ で不変。
- 表から作った $\eta_0$ の乗法の行列の固有多項式は、PARI の `polsubcyclo(p^2,p)` と一致し、既約である。

### 1.2 $\mathbb{Z}[1,\eta_0,\dots,\eta_{p-2}]$ は整数環：正しい

- この格子は積で閉じている（表が整数）。トレース形式の行列式は $41^{80}$、$43^{84}$。
- $K$ の判別式は、導手判別式公式（自明でない $p-1$ 個の指標の導手はどれも $p^2$）から $p^{2(p-1)}$。PARI の `nfdisc` も $41^{80}$、$43^{84}$。よって格子の $O_K$ での指数は 1。$\log\mathrm{rd}=\tfrac{2(p-1)}{p}\log p$（`verify.py` の `logrd` と同じ式）。
- $\mathbb{Z}[\eta_0]$ の $O_K$ での指数は 519 桁（$k_{41}$）、560 桁（$k_{43}$）。$T$ の素数のうち、これを割るものは $k_{41}$ で 13 個（313、487、509、761、787、857、937、2221、3833、16603、17123、27743、894779）、$k_{43}$ で 21 個（19、367、641、2137、2141、3331、…、4461929）。
- **$k_{43}$ の 19 について。** $19<43$ なので、$O_K/19\cong\mathbb{F}_{19}^{43}$ は 1 個の元では生成されない（指数は $19^{43}$ で割れる）。$\theta=\eta_0+t\eta_1$ の冪を使う `audit/k37/rows37.py` の作り方は 19 では使えない。監査側は別の作り方にした（§3.2）。`span.py` の作り方（拡大体 $\mathbb{F}_q[t]/(m)$ の位数 $M$ の元。19 の $M$ を法とする位数は 42）は、$q<p$ でもそのまま正しい。完全分解する素数の上の $p$ 個の素イデアルが相異なること、「消える値の個数＝指数なら指数はすべて 1」という推論は、$q$ と $p$ の大小によらない。19 は 5,371 行のうち 5,295 行に現れ、指数は最大 12。この全部の付値を PARI でも確かめた（§3.4）。

### 1.3 $p$ の上の素イデアルと、完全分解の判定：正しい

- $\pi=\prod_{h\in H}(1-\zeta^h)$ を周期の基底で書き、乗法の行列の行列式が 41、43 であることを計算で確かめた。$p$ は完全分岐するので、$p$ の上の素イデアルは $(\pi)$。
- $q\ne p$ が $K$ で完全分解することは、$q \bmod M\in H$、すなわち $q^{p-1}\equiv1 \pmod{p^2}$ と同値（$\mathrm{Gal}(K/\mathbb{Q})=(\mathbb{Z}/M)^\times/H$）。証明書の素因数と `span_primes.txt` の素数は、すべてこの条件をみたす相異なる素数である（素数性は自作の決定的な Miller–Rabin と PARI の `isprime` の両方）。

### 1.4 閾値 83、173：正しい

- 導出。$K/\mathbb{Q}$ は素数次数 $p$ の巡回拡大で、真の中間体は $\mathbb{Q}$ だけ。素数 $\ell\ne p$ が $h(K)$ を割るとする。類群の $\ell$ 部分は $\mathbb{Z}_\ell[G]$ 加群で、ノルム元は零として働く（$h(\mathbb{Q})=1$）ので、$\mathbb{Z}_\ell[x]/(\Phi_p)$ 上の加群。この環は $\mathbb{Q}_\ell$ の $f$ 次不分岐拡大の整数環の直積（$f$ は $\ell \bmod p$ の位数）なので、有限加群の位数は $\ell^f$ の冪。よって $\ell^f\mid h(K)$（van der Linden の Theorems 6, 8 の、この場合の内容。ノートの `prop:masley` の証明と同じ）。$p\nmid h(K)$ は岩澤の定理（$p$ だけが分岐し、完全分岐する $p$ 次巡回拡大）。したがって $h(K)>1$ なら $h(K)\ge\min_{\ell\ne p}\ell^f$。
- 計算（自作、試し割り）。$\ell<83$（$p=41$）、$\ell<173$（$p=43$）の全部の素数の位数を求めた。

| | $\min\ell^f$ | 達成する $\ell$ | 次に小さい値 | 閾値未満の素数の位数（抜粋） |
|---|---|---|---|---|
| $k_{41}$ | **83**（$=2\cdot41+1$） | 83（$f=1$） | 739、821 | 2:20、3:8、5:20、7:40、73:4、79:8 |
| $k_{43}$ | **173**（$=4\cdot43+1$） | 173（$f=1$） | 431、947 | 2:14、3:42、5:42、7:6、11:7、13:21、79:3 |

  $f=1$ は $\ell\equiv1 \pmod p$ のことで、最小は 83、173（$87=3\cdot29$、$130$ は合成数）。$f\ge2$ なら $\ell^f\ge\ell^2$ で、$\ell\ge11$ なら $121>83$、$\ell\ge17$ なら $289>173$。残る $\ell\le7$（$p=41$）、$\ell\le13$（$p=43$）は表の位数から $\ell^f>$ 閾値。
- `verify.py` の `hmin` は、$\ell$ を 2 から順に動かし、$\ell\ge$（それまでの最小値）になったら止める。$\ell^f\ge\ell$ なので、これで最小値が求まる。出力は 83、173 で、上と一致。
- 余裕：$h<83$ には $B>530.554/(41\cdot83)=0.1560$、$h<173$ には $B>530.554/(43\cdot173)=0.0714$ で足りる。実際の $B$ は 5.44、5.48。

### 1.5 (B)：Lemma 5.2 の仮定

`docs/audit_k37.md` の §1.7 のとおり（総実体、$S$ は「完全分解して単項素イデアルになる素数」の集合の部分集合で大きさの制限はない、仮定は Hilbert 類体の Dedekind ゼータ関数の GRH）。$K\subset\mathbb{Q}(\zeta_M)^+$（$-1\in H$）で総実。小さい素数 19 を $S$ に入れることにも制限はない。和は $m\le40$ の部分和（項は正なので下界）で、19 では $m>3$ の項も効く（$m\le3$ で打ち切ると和は 0.0010 小さくなる）が、$m\le40$ と全部の $m$ の差は表示桁に現れない（§3.6）。
