# 独立監査の結果（2026-11-22）

元のスクリプトを見ずに、方法の各段を再導出し、数値を別実装で再計算した結果。スクリプトは `audit/`。

結論：結果を変える誤りは見つからなかった。ただし、証明を書くときに明記すべき点が下のとおりある。

## 方法の各段

| 段 | 判定 | 明記すべきこと |
|---|---|---|
| A1：完全分解しない不分岐素数の上の素イデアルは単項 | 正しい | 分解群の固定体 $D$ で $q$ は完全分解し、$K/D$ で惰性。$D$ は真部分体 |
| A2：分岐素数 $p$ の上の素イデアルは単項（$p$ が $\mathbb{Q}(m/p^v)$ で完全分解しないとき） | 正しい | 理由は「分解体からの持ち上げ」ではない。$\mathrm{Gal}=\mathbb{Z}/p^v\times\mathbb{Z}/m'$ で $H=0\times\langle\varphi_p\rangle$ をとると、$H$ は惰性群と自明に交わり、$P=(P\cap K^H)O_K$。$\varphi_p\ne1$ のとき $K^H$ は真部分体 |
| A3：Miller の補題の一般形 | 正しい | Miller の Lemma 2.2（arXiv:1410.2921）は完全分解する有理素数の形。一般形は同じ議論（Hilbert 類体への明示公式）で出る。押さえているのは**広義の類数**。$S$ の素イデアルも広義の単項でよい |
| A4：階数定理 | 正しい | Masley, Cor. 2.15 を numdam で確認。合成数 $m$ にも適用できる |
| A5：$\ell\mid m$ の部分 | 正しい | $t\ge2$ の判定には $v_p(m)=1$、$p$ 奇数、$p\nmid h(K')$ が要る。「階数 $=t-1$」は単数の部分群で足りるが、「階数不足 $\Rightarrow p\mid h$」には単数群全体（または指数が $p$ と素な部分群）が要る |

A5 の判定は、$\mathbb{Q}(\sqrt d)\cdot B_{3,1}$ と $\mathbb{Q}(\sqrt d)\cdot B_{5,1}$（$d<400$）の 183 体で PARI の類群（GRH 下）と突き合わせ、不一致は 0 だった。

## PARI による別経路の確認

- `bnfinit` + `bnfcertify`（無条件）：$m=6,10,12$ で $h=1$。$m=14,15$ は 10 分で終わらず。
- `bnfinit`（GRH 下）：13 体すべてと $\mathbb{Q}(33)$ で類群は自明。
- 素数冪層：$B_{2,1},B_{2,2},B_{2,3},B_{3,1},B_{3,2},B_{5,1},B_{7,1}$ は `bnfcertify` で $h=1$。$B_{11,1},B_{13,1}$ は GRH 下のみ（文献では Miller が無条件で証明）。
