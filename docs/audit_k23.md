## 1. 数学の確認（`math23.py`、`field23.py`、`norm23.py`）

### 1.1 完全分解の判定：正しい
$(\mathbb{Z}/529)^\times$ は位数 $506=22\cdot23$ の巡回群で、最小の生成元は $5$ である（$2$ と $3$ は 23 を法とする位数が 11 なので生成元ではない）。位数 22 の部分群 $H$ は $\{x : x^{22}\equiv1 \bmod 529\}$ と一致し（22 個、$-1\in H$、$H=\langle 5^{23}\rangle$）、還元 $H\to(\mathbb{Z}/23)^\times$ は全単射である。$q\ne23$ が完全分解することは $q \bmod 529\in H$、すなわち $q^{22}\equiv1 \pmod{529}$ と同値である。両方の検証器と自作の判定はこれと一致する。`verify.py` と `relations_recheck.py` の $g$ はどちらも 5 で、剰余類は（集合として）自作のものと一致した。

### 1.2 判別式と $\log\mathrm{rd}$：正しい
PARI の `nfdisc(polsubcyclo(529,23))` は $23^{44}$。導手判別式公式でも、自明でない 22 個の指標の導手はどれも 529 なので $529^{22}=23^{44}$。$\log\mathrm{rd}=\tfrac{44}{23}\log23\in[5.998336760907939\pm4.7\cdot10^{-16}]$、$\mathrm{rd}=402.758\ldots$。`polsturm` で実根が 23 個（総実）であることも確かめた。

### 1.3 閾値 47：正しい
23 を法とする位数は、2 が 11、3 が 11、5 が 22（7、11、17、19 は 22、13 は 11）。
- $f=1$ は $\ell\equiv1 \pmod{23}$ のときで、最小の素数は 47（200 未満では 47 と 139）。
- $f\ge2$ で $\ell^f<47$ となりうるのは $\ell\le6$、すなわち $\ell\in\{2,3,5\}$ だが、$2^{11}$、$3^{11}$、$5^{22}$ はどれも 47 より大きい。
- 47 未満の素数 $\ell\ne23$ で $\ell^f<47$ となるものはない（自作のコードで全数確認）。$\ell<1000$ での $\min\ell^f$ も 47 だった。
真部分体は $\mathbb{Q}$ だけ（23 は素数）なので、階数定理の仮定は自明に満たされる。23 が類数を割らないことは岩澤の定理による（23 だけが分岐し、完全分岐。PARI の `idealprimedec` でも $e=23$）。`verify.py` の `hmin()` も 47 を返した。

### 1.4 周期の基底：正しい
$f=$`polsubcyclo(529,23)`（モニック）について、$\Phi_{529}$ を法とする厳密な計算で $f(\eta_0)=0$ を確かめ、`nfgaloisconj(f)` の 23 個から $\tau(\eta_0)=\eta_1$ となるものを選び、$\eta_j=\tau^j(\eta_0)$ がすべて $\sum_h\zeta^{5^jh}$ に等しいことを $\Phi_{529}$ を法として確かめた。
- $\eta_0+\cdots+\eta_{22}=0$（厳密）。
- $1,\eta_0,\dots,\eta_{21}$ の冪基底での座標の $23\times23$ 行列の行列式は 0 でない（$1/2.4996\ldots\times10^{122}$）。よって $\mathbb{Q}$ 上の基底。
- `relations_recheck.py` の乗法の表 `MULT`（$23\times23=529$ 個）を、自作の厳密なモデルで計算した $\eta_i\cdot(\text{基底}_k)$ の座標と比べ、**529 個すべてが一致した**（`mult_check23.py`）。座標はすべて整数なので、$\mathbb{Z}[1,\eta_0,\dots,\eta_{21}]$ は環で、整数係数の元は $O_K$ に入る。

$\pi=\prod_{h\in H}(1-\zeta^h)$ を $x^{529}-1$ を法として展開し、$H$ 不変であること（23 で割れる指数の係数が一定であることも含む）を確かめた。周期の基底では
