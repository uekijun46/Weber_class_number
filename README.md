# Weber_class_number

$\mathbb{Q}$ の円分 $\hat{\mathbb{Z}}$ 拡大の部分体の類数を、GRH を仮定せずに決めるための計算と証明。

状態：作業中・未査読（2026-11-23 時点）。

## 記号と用語

- $k_m$ は、$\mathbb{Q}$ の円分 $\hat{\mathbb{Z}}$ 拡大の $m$ 次の唯一の部分体を表す。$k_1=\mathbb{Q}$ で、$k_d\subset k_m$ は $d\mid m$ と同値。
- $m=p^n$ のとき、$k_{p^n}$ は円分 $\mathbb{Z}_p$ 拡大の第 $n$ layer。素数冪は必ず $k_{7^2}$ のように冪の形で書く。
- $m$ が素数冪でないとき、$k_m$ を「合成数次の layer」と呼ぶ。$k_6=k_2k_3$ など。
- 他の文献との対応：$k_{p^n}=\mathbb{B}_{p,n}$（Miller）、$k_{2^n}=\mathbb{B}_n$（$p=2$ の文献）、$k_m=\mathbb{Q}(m)$（Gras）。
- 「証明書」は、完全分解する素数 $p$ ごとに与える、ノルムが $\pm p$ の整数 $\alpha\in O_K$ のこと。「検証器」は、証明書と解析的な上界を計算し直すプログラムのこと。
- スクリプト名、ディレクトリ名（`B72/` など）、古い報告（`docs/literature.md`、`docs/audit.md`）には、以前の記号 $B_{p,n}$、$\mathbb{Q}(m)$、「層」「合成層」が残っている。

当面の対象は素数冪次の $k_{p^n}$。合成数次の結果（3 節）は保留。

## 1. $h(k_{7^2})=1$（49 次、導手 343）

GRH を使わない証明の計算部分が揃い、検証器の第三者監査も済んだ（`docs/audit_b72.md`）。到達できた文献の範囲では先行結果は見つかっていない。

### 証明の段

1. **証明書。** $p\le 2.2\cdot10^7$ かつ $p^6\equiv1 \pmod{343}$ をみたす素数（$k_{7^2}$ で完全分解する素数）は 28,381 個ある。そのすべてに、$|N(\alpha)|=p$ となる $\alpha\in O_{k_{7^2}}$ がある。よって、これらの $p$ の上の素イデアルはすべて単項。
2. **解析的な上界。** Miller の補題（arXiv:1410.2921, Lemma 2.2）を $c=80$ で使う。

| 量 | 値 |
|---|---|
| 積分 $I(80)$ | $\le 1.2651137825$ |
| 素数についての和 | $\ge 1.4092610134$ |
| $B$ | $\ge 0.0360122$ |
| 類数 | $h<160.7121$ |

3. **階数定理。** Masley の Cor. 2.15（巡回拡大 $E/F$ に対する一般形）と $h(k_7)=1$ より、素数 $\ell\ne7$ が $h$ を割れば $\ell^{\mathrm{ord}_{49}(\ell)}\mid h$。その最小値は $\ell=197$ のときの 197。
4. **岩澤の定理**より $7\nmid h$。
5. $h<160.7121<197$ なので $h=1$。

### 確認の状況

- 検証器 `B72/verify_cert.py`（FLINT と Arb、PARI 不使用）が全行と上界を確認。
- `audit/b72_indep_check.py`：全行を PARI の別経路（極大整環への所属と終結式）で再確認。
- 第三者監査（`docs/audit_b72.md`）：補題の定数と仮定を文献と照合。積分と素数についての和を別の方法（テイラーモデル、区間演算）で再計算し一致。全行を別実装で再確認。$h(k_7)=1$ を `bnfcertify` で無条件に確認。
- 監査の指摘で直した点：検査を `assert` から明示的な失敗に変更。表示する数値を安全な向きに丸めるよう変更（以前の表示「$h<160.71$」は丸めのため不等式として正しくなかった。正しくは $h<160.7121$）。

### 再現

pip install python-flint cypari2
cd B72 && python3 verify_cert.py cert*.txt        # 約 40 分

## 2. 生成元の求め方の改良と $k_{3^4}$

PARI の類群計算を使わず、小さい元 $c+\sum a_i\eta_i$（$\eta_i$ は Gauss 周期）のノルムの素因数分解から単項性を導く方法を `relations/` に実装した。詳細は `relations/README.md`。

- **$k_{7^2}$**：2 つ目の証明書（2.4 MB）で $h<152.0639<197$。検証は約 9 秒、探索は 2 コアで約 20 分。
- **$k_{3^4}$（81 次、導手 243）**：$3\cdot10^{10}$ 未満の完全分解素数 16,049,777 個すべてに検証済みの行があり、上界は $h<99.8767<163$（$c=100$）。$k_{3^4}=\mathbb{Q}(\zeta_{243})^+$ で、GRH 下でしか知られていなかった。検証器と論理の独立監査（`docs/audit_relations.md`）で、証明を壊す誤りは見つからなかった。真部分体の類数 1 も文献に頼らずに確かめた（`relations/subfields.py`）。MathSciNet での確認でも先行結果は見つからなかった。文章化はこれから。
- **定数倍の改良と $k_{29}$ の試行**：`docs/improvements.md`。分岐する素数の項を足すと上界は $h(k_{3^4})<65.92$、$h(k_{7^2})<93.94$ になる（ノートでは未使用）。$k_{29}$ は全区間が通り、$h(k_{29})<42.7877<59$（`relations/README.md`。監査はこれから）。
- **ノートの第一稿**：`paper/k49_k81.tex`（$k_{3^4}$、$k_{7^2}$、$k_{29}$ を新しい方法でまとめたもの）。
- 小さい元のノルムの大きさは $p$ で決まる。$p$ が小さいほど小さい（`explore/norm_yield.py`）。

| 体 | 次数 | 小さい元のノルムの中央値 |
|---|---|---|
| $k_{3^4}$ | 81 | $10^{12}$ |
| $k_{7^2}$ | 49 | $10^{18}$ |
| $k_{29}$、$k_{31}$ | 29、31 | $10^{20}$、$10^{22}$ |
| $k_{37}$、$k_{47}$ | 37、47 | $10^{28}$、$10^{38}$ |
| $k_{5^3}$、$k_{11^2}$ | 125、121 | $10^{35}$、$10^{57}$ |

その先の候補：無条件の $k_{29}$、$k_{31}$。GRH を仮定する $k_{37}$〜$k_{47}$ は、PARI の `bnfinit` が $k_{37}$ で 9 分半では終わらず、この方法でもノルムが大きいので後回し。

## 3. 合成数次の layer（保留）

$m=6,10,12,14,15,18,20,21,22,24,26,28,36$ で、`composite/` の検証器が $h(k_m)=1$ の上界条件に合格している。方法と数値の独立監査は `docs/audit.md`、文献照合は `docs/literature.md`。$m=6,10,12,18,24$ は既知。残り 8 個は、到達できた文献では GRH 下の記載しか見つかっていない。

類数が 1 でない既知の例（Gras の論文の脚注と Fukuda のスライドによる）：

- $p\mid m$ の型：$31\mid h(k_{2\cdot31})$、$73\mid h(k_{3\cdot73})$（Horie 2001）、$1546463\mid h(k_{2\cdot1546463})$、$18433\mid h(k_{2^8\cdot18433})$、$114689\mid h(k_{2^{10}\cdot114689})$、$487\mid h(k_{3^4\cdot487})$、$238627\mid h(k_{3^4\cdot238627})$、$2251\mid h(k_{5^2\cdot2251})$。
- $p\nmid m$ の型：$107\mid h(k_{2\cdot53})$（Aoki–Fukuda）。
- これらを含む $k_m$ も類数が 1 でない。次数が最小の既知の例は $m=62$。

再検証（約 2 分）：`cd composite && sh rig_run_all.sh`。
