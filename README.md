### 証明の組み立て

$K=\mathbb{Q}(m)$ は $\mathbb{Q}$ 上巡回。真部分体の類数がすべて 1 と仮定する（表の並び順が帰納の順序）。

1. 完全分解しない素数の上の素イデアルは、分解体からの持ち上げなので単項。証明書が要るのは完全分解する素数だけ。
2. 完全分解する素数 $q\le X$ には、ノルム $\pm q$ の代数的整数を証明書として与える。
3. Miller の補題（無条件版）で $h$ の上界を出す。
4. $\ell\nmid m$：階数定理より $h>1 \Rightarrow h\ge \ell^{\mathrm{ord}_m(\ell)}\ge h_{\min}$。
5. $\ell\mid m$：分岐する素点が 1 個なら $\ell\nmid h$。2 個以上なら Chevalley の公式と単数の局所ノルム記号で判定（$m=14,28$ の 7 部分）。

### 前提（検証器が信頼しているもの）

- Miller の補題の一般形（総実体、単項素イデアルの任意の集合、剰余次数は任意）。
- Masley の階数定理（Compositio Math. 37 (1978), Cor. 2.15）。
- Chevalley の公式、Hasse のノルム定理、局所類体論。
- 素数冪層 $B_{2,1},B_{2,2},B_{2,3},B_{3,1},B_{3,2},B_{5,1},B_{7,1},B_{11,1},B_{13,1}$ の類数 1（既知）。
- FLINT / Arb の正しさ。PARI は証明書の探索にだけ使い、出力はすべて再検証する。

## 2. $B_{7,2}$（49 次、導手 343）：検証器が合格

$h(B_{7,2})=1$ の、GRH を使わない証明の計算部分が揃った（2026-11-23）。到達できた文献の範囲では先行結果は見つかっていない。未査読。

- 証明書：28,381 個。$2.2\cdot10^7$ 以下で完全分解する素数（$p^6\equiv1 \pmod{343}$）のすべて。各行はノルム $\pm p$ の代数的整数。単項でない素イデアルは 1 つも現れなかった。
- 検証器 `B72/verify_cert.py`（FLINT と Arb、PARI 不使用）の出力：

| $c$ | 積分 $\le$ | 素数和 $\ge$ | $B\ge$ | $h<$ |
|---|---|---|---|---|
| 60 | 1.26602242 | 1.39423010 | 0.020073 | 216.25 |
| 80 | 1.26511378 | 1.40926101 | 0.036012 | **160.71** |
| 100 | 1.26469275 | 1.41632609 | 0.043498 | 166.32 |

- 結論までの段：
  1. Miller の補題（arXiv:1410.2921, Lemma 2.2。完全分解して単項になる素数の集合に対する形そのまま）より $h<160.71$。
  2. Masley の階数定理（Cor. 2.15）と $h(B_{7,1})=1$ より、素数 $\ell\ne7$ が $h$ を割れば $\ell^{\mathrm{ord}_{49}(\ell)}\mid h$。その最小値は $\ell=197$ のときの 197。
  3. 岩澤の定理より $7\nmid h$。
  4. よって $h=1$。
- 独立な確認：
  - `audit/b72_indep_check.py`：全 28,381 行を PARI の別経路（極大整環への所属と終結式）で再確認。全行合格。
  - 上界を mpmath で再計算し、$c=80$ で $h<160.71$ に一致。
- 再現：`cd B72 && python3 verify_cert.py cert*.txt`（約 40 分）、`python3 audit/b72_indep_check.py 0 1`（約 12 分、リポジトリの根で実行）。
- 証明書の生成は GitHub Actions（`b72-certificates`）で行った。PARI の `bnfinit` は探索にだけ使っている。

前提として信頼しているもの：上の 1〜3 の定理、$h(B_{7,1})=1$（既知）、FLINT / Arb / PARI の `nfinit` の正しさ。`verify_cert.py` 自体は、合成層の検証器と違い、第三者による監査をまだ受けていない。

## 3. 類数が 1 でない既知の例

$\mathbb{Q}(62)$（$31\mid h$）、$\mathbb{Q}(219)$（$73\mid h$）は Horie (2001) による。$(1+\sqrt2)^{30}\equiv1 \pmod{31^2}$ のような Wieferich 型の一致で起こる。$p\nmid m$ 型の唯一の既知例は $107\mid h(\mathbb{Q}(106))$（Aoki–Fukuda）。既知の最小次数は 62。詳細は `docs/literature.md`。
