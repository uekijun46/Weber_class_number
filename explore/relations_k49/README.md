# relations_k49/：小さい元の関係式による単項性の証明（試作、非厳密）

$k_{7^2}$ で、PARI の類群計算を使わずに素イデアルの単項性を導く試作。ノルムは固定小数点で計算しており、まだ厳密ではない。検証器も未作成。

## 考え方

- 元は $\alpha=c+\sum_k s_k\eta_{i_k}$（$\eta_i$ は Gauss 周期、$s_k=\pm1$、項は 1〜5 個、$|c|\le2$）。
- 行：$\alpha$ と $|N(\alpha)|$ の素因数分解。完全分解する素数 $q$ がノルムをちょうど 1 回割り、他の素因数がすべて「7」「完全分解しない素数」「すでに単項と分かっている完全分解素数」なら、$q$ の上の素イデアルは単項。
- 最小の完全分解素数 19 はほとんどのノルムを割るので、別に処理する。ノルムが $7^a19^k$ の元について、19 の上の 49 個の素イデアルでの付値を計算する。その巡回シフトが $\mathbb{Z}^{49}$ を張れば単項（`boot19.py`）。

## 結果（2026-11-24、2 コア、Python）

- 19：3 個の元 $-2-\eta_0-\eta_{24}$、$-2-\eta_0-\eta_{25}$、$-1-\eta_0$（ノルム $7\cdot19^4$、$7\cdot19^4$、$7\cdot19^3$）で、関係式の格子が $\mathbb{Z}^{49}$ 全体になった。
- 無作為な元 200 万個（約 8 分）：単項と分かった素数は計 261,669 個。$2.2\cdot10^7$ 以下の 28,381 個のうち 13,271 個（$10^6$ 以下は 1601 個中 1598 個）。
- この集合だけでは Miller の補題の $B$ はまだ正にならない。残りの素数を狙って探す手続きが必要。

## ファイル

- `proto.py`：元の生成、ノルム、因数分解、依存関係の解消。`python3 proto.py 600000 1 1000000`
- `boot19.py`：19 の処理。
- `cover.py`：元を追加して被覆を数える。`bound_now.py`：得られた素数の集合での上界（`B72/verify_cert.py` の関数を使う。パスは要調整）。
