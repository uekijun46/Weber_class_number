# relations/：小さい元の関係式による単項性の証明

PARI の類群計算（`bnfinit`、`bnfisprincipal`）を使わずに、$k_{p^n}$（$p$ は奇素数）で完全分解する素数の上の素イデアルが単項であることを示す。

## 考え方

- 元は $\alpha=c+\sum_i a_i\eta_i$ と書く。$\eta_i$（$i$ は $p^n$ を法とする）は Gauss 周期で、$\mathrm{Gal}(k_{p^n}/\mathbb{Q})$ の生成元は $\eta_i\mapsto\eta_{i+1}$。
- **行**：完全分解する素数 $q$、元 $\alpha$、$|N(\alpha)|$ の素因数分解の組。$q$ がノルムをちょうど 1 回割り、他の素因数 $r$ がすべて次のどれかなら、$q$ の上の素イデアルは単項である。
  - $r=p$（$p$ の上の素イデアルは単項）
  - $r$ は完全分解しない（真部分体の類数が 1 なら、$r$ の上の素イデアルは単項）
  - $r$ は完全分解し、その上の素イデアルが単項であることが先に示されている
- **範囲の形式**：区間 $[A,B)$ の完全分解素数 $q$ すべてに、「他の完全分解する素因数は $q$ より小さい」という行を与える。$A$ 未満がすべて済んでいれば、$q$ についての帰納法で $B$ 未満がすべて単項になる。区間ごとに独立に計算と検証ができる。
- **格子ブロック**：最小の完全分解素数がほとんどのノルムを割る場合（$k_{7^2}$ の 19）に使う。ノルムが $p^aq_0^k$ で、$q_0$ の上の相異なる $k$ 個の素イデアルにちょうど 1 回ずつ入る元を集める。その共役すべての 0/1 ベクトルが $\mathbb{Z}^N$ を張れば、$q_0$ の上の素イデアルは単項。

## プログラム

| ファイル | 役割 | 信頼 |
|---|---|---|
| `verify.py` | 検証器。ノルムは補助素数での計算と中国剰余定理で厳密に求める。素数性は証明つきの判定。上界は区間演算 | 信頼する側。python-flint のみ使用 |
| `aggregate.py` | 区間ごとの検証結果（`summary_A_B.json`）を合わせて類数の上界を出す | 信頼する側 |
| `field.py`、`collect.py`、`search.py`、`export.py`、`gen_range.py` | 行の探索（無作為な小さい元、素数ごとの格子の簡約）。ノルムは固定小数点、因数分解は PARI | 信頼しない。出力は `verify.py` が確かめる |
| `need_k81.py` | $k_{3^4}$ に必要な範囲の見積もり（浮動小数） | 見積もり用 |

## 結果

### $k_{7^2}$：既存の証明と独立な 2 つ目の証明書

- `cert_k7_2.txt`（2.4 MB、29,834 行と 19 の格子ブロック）。$2.2\cdot10^7$ 以下の完全分解素数 28,381 個すべてを含む。
- `python3 verify.py cert_k7_2.txt` は約 9 秒で、$c=80$ のとき $h<152.0639<197$。
- 探索は 2 コアで約 20 分（PARI による以前の方法は約 100 コア時間、証明書は 187 MB）。

### $k_{3^4}$：進行中（無条件では未解決の体。GRH 下では van der Linden 1982）

- 必要な範囲の見積もり：完全分解素数（$q\equiv\pm1 \bmod 243$）を $3\cdot10^{10}$ まで、約 1605 万個。そのとき $c=100$ で $h<100$ 程度の見込み（閾値は 163）。$2\cdot10^{10}$ では $h<176$ で足りない。
- 済んだ部分：`k3_4/base_cert.txt`（$10^7$ 未満の 8160 個、検証済み）と、区間 $[10^7,1.4\cdot10^7)$（GitHub Actions、検証済み）。
- 1 素数あたり 20〜35 ミリ秒（1 コア）。全体で 100〜160 コア時間の見込み。
- 残りの区間は GitHub Actions の `relations-ranges` で計算する：`p=3, n=4, lo=14000000, hi=30000000000, jobs=80`。終わったら `python3 aggregate.py k3_4`。

## 使い方

```sh
pip install python-flint cypari2 mpmath
python3 verify.py cert_k7_2.txt                                   # k_{7^2} の検証
python3 verify.py k3_4/base_cert.txt --complete 10000000          # k_{3^4} の基礎部分
python3 gen_range.py 3 4 A B rows.txt 4 && python3 verify.py rows.txt --range A B
python3 aggregate.py k3_4
```
